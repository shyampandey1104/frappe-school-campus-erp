# 🎓 Frappe School & Education Campus ERP

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![ERPNext](https://img.shields.io/badge/Frappe-Education-blue.svg)](https://frappeframework.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An **Education Campus & Student Academic Management Engine** for **Frappe Framework**. Manages student admissions, grade batches, multi-component fee structures (tuition, lab, library, transport), and examination report card generation with automated grade assignments.

---

## ⚡ Highlights
- 🧑‍🎓 **Student Enrollments**: Grade levels, batch section assignment, and roll numbers.
- 💳 **Fee Collection**: Multi-term fee breakdown and automatic total calculations.
- 📜 **Report Cards**: Automatic percentage, letter grade (`A+`, `A`, `B`), and pass/fail evaluation.
- 🧪 **Pytest Coverage**: Unit tests included.
